# greactor-ql

Go implementation of the reactor-ql project: a small SQL-over-stream engine for message transformation.

> Status: **experimental scaffold** (v0.0.0-dev).

## Planned features

- `select` / `where` / expression subset over a single message row
- Compatibility subset for existing reactor-ql conversion rules
- Pluggable input/output adapters

## Install

```bash
go get github.com/maxid/greactor-ql
```
