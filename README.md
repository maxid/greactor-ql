# greactor-ql

A small SQL-over-stream engine for message transformation in Go.

> Status: **experimental scaffold** (v0.0.0-dev).

## Planned features

- `select` / `where` / expression subset over a single message row
- Pluggable input/output adapters
- Deterministic, test-friendly evaluation

## Install

```bash
go get github.com/maxid/greactor-ql
```
